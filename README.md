# 戸建て投資シミュレータ

戸建て物件の取得・運用・売却を、基準・楽観・慎重の3ケースで比較するWebアプリです。リポジトリに同梱した架空物件のCSVを読み込み、画面で条件を編集して試算します。

試算は入力した仮定に基づく税引前の概算です。税務・融資判断や実際の投資成果を保証するものではありません。

## 主な機能

- サンプル物件CSVを読み込み、物件・購入費用・賃貸・融資条件を設定
- 年次運用収支、修繕予定、ローン残債、売却後手残りを試算
- 基準・楽観・慎重の3ケースを編集し、主要指標・年次推移グラフ・詳細表で比較
- 試算条件をJSONでダウンロード・取り込み
- 3ケースの年次結果をCSVでダウンロード
- ライトモード／ダークモードの切り替え

## データの扱い

- サンプル物件データは [`public/data/sample-properties.csv`](public/data/sample-properties.csv) にあります。サンプルは架空のデータです。
- 画面で編集した試算条件や計算結果は、アプリ内に継続保存されません。JSONへ出力し、必要なときに取り込んでください。
- JSON・CSVファイルはブラウザー内で生成します。試算条件や結果をサーバーへ送信しません。
- ダークモードの選択だけは、次回アクセス時にも維持するためブラウザーのローカルストレージに保存します。

## 開発環境

- Node.js 26.x（CIの検証環境）
- npm

依存関係をインストールし、開発サーバーを起動します。

```bash
npm ci
npm run dev
```

ブラウザーで <http://localhost:3000> を開きます。

## 検証コマンド

```bash
npm test -- --runInBand
npm run lint
npm run build
```

## 主な構成

| パス | 内容 |
| --- | --- |
| `src/app/page.tsx` | サンプルCSVの読み込みとメイン画面 |
| `src/app/components/` | 条件入力、ケース比較、グラフ、ダークモード |
| `src/lib/` | CSV解析、投資・運用・売却の計算、JSON/CSV処理 |
| `public/data/sample-properties.csv` | 同梱するサンプル物件 |
| `docs/` | 開発計画、フェーズごとの要件・設計、調査レポート |
| `__tests__/` | 計算・画面・ダークモードのテスト |
