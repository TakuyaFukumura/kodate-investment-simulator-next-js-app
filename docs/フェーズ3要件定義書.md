# フェーズ3 要件定義書：売却・投資全体の収益確認

## 1. 文書の状態

- **状態**：実装仕様
- **対象フェーズ**：フェーズ3
- **関連文書**：[開発計画書](戸建て投資シミュレータ開発計画書.md)、[フェーズ1要件定義書](フェーズ1要件定義書.md)、[フェーズ2要件定義書](フェーズ2要件定義書.md)、[フェーズ3設計書](フェーズ3設計書.md)、[意思決定記録](意思決定記録.md)

## 2. 目的と対象範囲

フェーズ2の各年次運営CFに売却価格、売却費用、売却年末のローン残債を加え、保有年数ごとに売却後手残りと投資全体の損益を確認できるようにする。売却価格・費用・融資は仮定に基づく税引前概算とする。

### 2.1 対象機能

- フェーズ2の予測期間（1〜50年）について、各年末に売却する場合の結果を年ごとに計算する。
- 1つの想定売却利回りを入力し、全ての売却年に共通適用する。初期値は空欄とし、利用者の入力後に結果を表示する。
- 売却年のNOIを想定売却利回りで割って売却価格を算出する。
- 売却価格に連動する仲介手数料を、通常の法定上限額で計算する。800万円以下の低廉な空家等の媒介特例は、利用者が適用を選択できる。
- 印紙税、ローン完済手数料、その他売却費用はそれぞれ入力し、全売却年に共通適用する。
- 年次運営CF累計、売却価格、売却費用内訳、売却時残債、売却後手残り、総損益、単純損益率を表に表示する。
- 総損益の推移をグラフで表示する。
- 有効な入力変更に合わせて即時再計算する。基本入力、運用予測条件または売却条件が不正な場合、売却結果を表示しない。
- 条件や結果は保存しない。物件を切り替えるとフェーズ2・3の条件を初期状態に戻す。

### 2.2 対象外

- 譲渡所得税、所得税、消費税の計算、税引後の損益。
- IRR、NPV、資金調達コスト・資本コストを考慮した評価。
- 売却年ごとに異なる売却利回り、売却費用の入力。
- 売却価格の市場データ取得、価格変化率入力、査定価格の保証。
- 仲介手数料以外の税額・法定費用の自動計算。印紙税等は利用者入力とする。

## 3. 入力と検証

| 入力 | 仕様 |
| --- | --- |
| 想定売却利回り | %／年。0より大きく100%以下、小数第2位まで。初期値は空欄。1つの値を全売却年で共通使用する |
| 印紙税 | 万円。0以上、0.1万円単位。全売却年に共通 |
| ローン完済手数料 | 万円。0以上、0.1万円単位。全売却年に共通 |
| その他売却費用 | 万円。0以上、0.1万円単位。全売却年に共通 |
| 低廉な空家等の媒介特例 | 初期値オフのチェック項目。該当する売却価格が800万円以下で、対象要件と売主の合意を確認した場合に選択する |

仲介手数料は手入力せず、各年の売却価格から計算する。基本試算の物件価格・取得費用・初回リフォーム費用・借入額をフェーズ1から引き継ぐ。

## 4. 計算定義

保有年を `y`、想定売却利回りを `c`（%）、フェーズ2の年次予測を `P_y` とする。

1. **売却価格** ＝ `P_y.NOI ÷ (c / 100)`。NOIが0以下の場合は売却価格を算出せず、その年の売却結果を「算出不可」とする。
2. **通常仲介手数料上限（税込）**：売却価格（万円）を基礎として、200万円以下の部分に5.5%、200万円超〜400万円以下の部分に4.4%、400万円超の部分に3.3%を適用して合算する。
3. **特例適用時の仲介手数料**：売却価格が800万円以下で特例チェックが有効な売却年では、条件適合と売主合意を前提に33万円（税込）を上限額として用いる。800万円を超える年は通常仲介手数料を用いる。チェックだけで適用要件を満たすことを保証しない。
4. **売却費用合計** ＝ 仲介手数料 + 印紙税 + ローン完済手数料 + その他売却費用。
5. **売却後手残り** ＝ 売却価格 − 売却費用合計 − 当年末ローン残債。負の値も表示する。
6. **初期自己資金** ＝ フェーズ1の総事業費 − 借入額。総事業費は物件価格 + 項目別取得費用 + 初回リフォーム費用。
7. **総損益** ＝ 当年までの累計運営CF + 売却後手残り − 初期自己資金。
8. **単純損益率** ＝ 総損益 ÷ 初期自己資金 × 100。初期自己資金が0以下の場合は算出せず「—」とする。

各保有年の年次CFには当年の年間運営CFを含め、その年末のローン返済後残債を売却時に一括返済する。取得時支出は初期自己資金に含め、譲渡税等は含めない。金額は内部で丸めず、表示時に万円単位小数第1位、割合は小数第2位に整形する。

## 5. 表示・受け入れ条件

- 想定売却利回りが空欄または不正な間、売却結果を表示しない。エラーを入力欄に関連付けて表示する。
- 有効な利回りを入力すると、各保有年について年次CF累計、NOI、売却価格、仲介手数料、その他売却費用、年末残債、売却後手残り、総損益、単純損益率を表示する。
- NOIが0以下の年は運営CFを表示したまま、売却価格とそれに基づく結果を算出不可として明示する。
- 初期自己資金が0以下の場合でも総損益は表示し、単純損益率は「—」とする。
- 特例は売却価格800万円以下の年にだけ適用され、選択状態、対象条件、売主合意を確認する説明を表示する。
- 仲介手数料の通常上限は価格帯ごとの段階料率で計算し、境界値200万円・400万円・800万円を検証する。
- 保有期間、運営条件、売却利回り、費用の変更が表・グラフ・合計値に即時反映される。
- 税務・法務判断や将来価格・投資成果の保証ではない旨を表示する。

## 6. 制度上の注意

仲介手数料は法令上の上限額を用いる概算であり、実際の報酬額や上限の適用は取引条件・課税関係・媒介契約等により異なる。800万円以下の低廉な空家等の特例は、要件適合と依頼者の合意が前提であり、チェック項目は利用者がそれを確認したことを示す。詳細は国土交通省の[不動産取引に関するお知らせ](https://www.mlit.go.jp/totikensangyo/const/1_6_bf_000013.html)および[報酬額告示改正資料](https://www.mlit.go.jp/tochi_fudousan_kensetsugyo/const/content/001749923.pdf)を参照する。
