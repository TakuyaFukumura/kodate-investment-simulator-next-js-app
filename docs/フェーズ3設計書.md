# フェーズ3 設計書：売却・投資全体の収益確認

## 1. 文書の状態

- **状態**：実装設計
- **関連要件**：[フェーズ3要件定義書](フェーズ3要件定義書.md)
- **前提仕様**：[フェーズ1要件定義書](フェーズ1要件定義書.md)、[フェーズ2要件定義書](フェーズ2要件定義書.md)

## 2. 構成と責務

- `src/lib/exit.ts`：売却条件の検証、仲介手数料上限、保有年ごとの売却後手残り・投資損益の純粋計算。
- `src/app/components/ExitPanel.tsx`：想定売却利回り、費用、特例の入力と結果表を表示する。
- `src/app/components/ExitChart.tsx`：保有年別の総損益をSVG棒グラフで表示する。
- `src/app/components/ProjectionPanel.tsx`：有効な基本入力と年次予測をExitPanelへ渡す。既存のフェーズ2条件と同じライフサイクルで物件選択時に初期化する。
- `docs/意思決定記録.md`：利用者が決めた仕様と未決定事項を区別して記録する。

## 3. 計算処理

- `calculateExitScenarios` は有効なフェーズ1入力、フェーズ2年次予測、売却条件を受け取る。
- 年次予測を売却年1年目から走査し、同じ想定売却利回りと売却費用の前提で各年の出口結果を算出する。
- 売却利回りは `0 < rate <= 100`、小数第2位までとする。空欄はUIで未入力として扱い、計算関数には渡さない。
- 通常仲介手数料は万円単位の価格に対し、`min(price, 200) * 0.055 + max(min(price - 200, 200), 0) * 0.044 + max(price - 400, 0) * 0.033` を使用する。段階料率は税込の上限率。
- 低廉な空家等の特例を選択した場合、売却価格が800万円以下の年の仲介手数料は33万円とする。売却価格が800万円を超える年は通常料率に戻す。
- 修繕・年間CF累計と年末残債はフェーズ2の結果を再利用し、二重計算しない。
- 売却年のNOIが0以下の行は、売却価格・仲介手数料・売却後手残り・総損益・単純損益率を `null` とする。年次CF・累計運営CF・残債は表示を継続する。
- 初期自己資金は `InvestmentResult.totalProjectCostMan - input.loanAmountMan`。0以下の場合は総損益を計算し、単純損益率だけ `null` とする。
- 計算途中で丸めず、費用合計と売却後手残りを通常の数値演算で算出し、UI表示時に整形する。

## 4. 入力・エラー表示

- 利回りは文字列で保持し、空欄・数値でない値・0以下・100%超・小数第3位以降を項目エラーとして表示する。
- 印紙税・ローン完済手数料・その他売却費用は文字列で保持し、0以上の有限値、0.1万円単位を検証する。
- フェーズ1または2の条件にエラーがあれば売却結果を表示しない。売却入力が不正な場合も前回の結果を残さない。
- 特例チェックは初期オフとする。売却価格に応じて特例が利用できる年を判定し、チェックの説明に「条件適合と売主合意を確認した場合」と記載する。

## 5. 表示

- 結果サマリー：選択中の売却年という追加選択状態は設けず、各年を1行で一覧する。
- 年次表：保有年、運営CF累計、NOI、売却価格、仲介手数料、印紙税、ローン完済手数料、その他、売却時残債、売却後手残り、総損益、単純損益率。
- 総損益グラフはゼロ基準線を用い、黒字・赤字を色と数値で判別する。年ラベルは50年でも読み取れるよう間引く。
- 横幅が画面を超える表は横スクロール可能とし、グラフに依存せず全ての値を表でも提示する。
- 免責表示で、税引前概算・譲渡税対象外・価格および手数料の仮定依存を明記する。

## 6. テスト設計

- 仲介手数料：価格0、200万円境界、400万円境界、800万円境界、特例選択の前後。
- 投資全体計算：売却利回りによる価格、売却費用、年末残債控除、取得時の初期自己資金控除、累計CF、単純損益率、自己資金0以下、NOI非正の年。
- 検証：空欄、0以下、100%超、小数精度超過、費用負値・小数第2位以降。
- 画面：利回り・費用変更の即時反映、特例選択、無効入力時の結果抑止、年別一覧とグラフ、基本入力無効時の抑止、物件切り替え時の初期化。
- 回帰：フェーズ1・2の試算、ダークモード、CSV読み込みを維持する。
