入力フォームは文字列状態を保持し、空欄や編集中の値を失わない。値がすべて有効なときだけ計算関数を呼び出す。計算関数は画面やCSVに依存しない。

## 3. CSV仕様

### 3.1 ファイルと列

UTF-8 BOM付き、カンマ区切り、CRLFまたはLF改行、1行目ヘッダーとする。フィールドはRFC 4180形式の引用符・引用符エスケープを扱う。列順は固定し、余分な列・不足列・重複列をエラーとする。

| 列名 | 内容 | 単位 |

| `id` | 一意な物件識別子 | 文字列 |
| `name` | 物件サンプル名 | 文字列 |
| `description` | 物件の架空条件の説明 | 文字列 |
| `purchasePriceMan` | 物件価格 | 万円 |
| `monthlyRentMan` | 月額家賃 | 万円／月 |
| `brokerageFeeMan` | 仲介手数料 | 万円 |
| `registrationFeeMan` | 登記・司法書士費用 | 万円 |
| `stampTaxMan` | 印紙税 | 万円 |
| `acquisitionTaxMan` | 不動産取得税 | 万円 |
| `loanFeeMan` | 融資手数料 | 万円 |

CSVの不正を検出した場合は全体を拒否し、1始まりのCSV行番号と列名を含むエラーを返す。空行は無視せず不正行として扱う。空CSVやヘッダーだけのCSVもエラーとする。

## 4. 計算関数設計

`calculateInvestment(input)` は、検証済みの数値入力を受けて、家賃・空室損失・運営費・NOI・総事業費・各利回り・返済額・年間／月平均CF・DSCRを返す。検証関数はすべての不正項目を収集し、`field` と利用者向け `message` を返す。

元利均等返済は月利 `annualInterestRatePercent / 1200`、返済回数 `loanTermYears * 12` で計算する。年利が0%なら `loanAmountMan / repaymentCount`、それ以外は `loanAmountMan * monthlyRate / (1 - (1 + monthlyRate) ** -repaymentCount)` を月返済額とする。借入額0の場合は返済額0とする。途中で丸めず、表示層で整形する。

## 5. 画面・状態設計

- 初期表示はCSV読み込み中とし、取得・解析の成功後に物件選択とフォームを表示する。
- 通信失敗、HTTP失敗、CSV構文・内容不正はエラー表示と再試行操作を出す。部分的な物件データでは動作しない。
- 物件を切り替えると、その物件のCSV初期値で全入力を置き換える。
- 数値入力は文字列で管理する。空欄・不正値がある場合は項目ごとのエラーを表示し、指標・グラフを隠す。
- 有効な値では入力ごとに計算し、指標とグラフを同期して表示する。
- CSV値・編集値・計算結果は永続化しない。
- 年利0%でも計算を成立させ、返済額0のときDSCRは「—」とする。

## 6. グラフ設計

外部グラフライブラリを追加せず、SVGでウォーターフォールを描画する。系列は満室想定年間家賃、空室損失、年間運営費、NOI、年間返済額、税引前年間CF。控除は負の差分、NOIとCFは累積値の合計バーとして表示する。正負のCFに対応したゼロ基準線を設け、棒の色だけに依存せず項目名・金額も併記する。

## 7. テスト設計

- CSV：BOM、引用符とエスケープ、CRLF/LF、正常な2行、ヘッダー欠落・重複・余分な列、列数不一致、空行、空欄、不正数値、範囲外値、重複ID。
- 計算：利回り・NOI・費用合計、標準金利返済、年利0%、借入0、空室0/12、負のCF、途中丸めをしないこと。
- 画面：CSV読み込み、物件切り替え、即時再計算、不正入力時に結果を隠す、CSVエラーと再試行、グラフ・結果の表示。
- 回帰：ダークモードの切り替えと保存済みテーマの読み込み。
