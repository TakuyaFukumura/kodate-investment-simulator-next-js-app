# フェーズ5 要件定義書：統合・品質向上・テンプレート機能の整理

## 1. 文書の状態

- **状態**：完了（2026-11-15）
- **対象フェーズ**：フェーズ5
- **関連文書**：[開発計画書](戸建て投資シミュレータ開発計画書.md)、[プロダクト要件定義書](プロダクト要件定義書.md)、[意思決定記録](意思決定記録.md)、[設計書](フェーズ5設計書.md)
- **前提要件**：フェーズ1〜4の要件定義書・設計書

## 2. 目的と対象範囲

既存の投資シミュレーションをアプリの中心機能として統合し、不要なテンプレート機能を除去する。既存の計算機能を変更せず、利用説明・アクセシビリティ・ダークモードを含む全体品質を確認する。

### 2.1 対象

- テンプレート由来のメッセージAPI、SQLiteアクセス、関連する型・テスト・依存関係を削除する。
- READMEを現在の戸建て投資シミュレータの機能・起動・検証方法に合わせる。
- ダークモードの切り替えと選択状態の保持を維持する。ローカルストレージに保存するのはテーマ選択だけとし、試算条件・計算結果は保存しない。
- 見出し構造を整理し、テーマ切替ボタンにアクセシブルな名前と状態を付与する。
- ページタイトル・説明文をアプリの実際の機能に合わせる。
- サンプルCSV読込、フェーズ1〜4の計算・比較・ファイル入出力、画面幅、キーボード操作、ダークモードを回帰確認する。

### 2.2 対象外

- 新しい投資計算機能、税引後計算、認証、外部サービス連携。
- 試算条件や計算結果のDB・ブラウザー内への継続保存。
- デプロイ先の変更や新たな運用基盤の追加。

## 3. 共通品質要件

- 投資計算・サンプル物件読込・JSON/CSV処理の既存仕様を維持する。
- ローディング、サンプルデータ読込失敗、入力エラーを利用者が判別できる状態を維持する。
- アプリ名をページの主見出しとして示し、ヘッダーのブランド表示によって見出し階層を重複させない。
- テーマ切替ボタンはキーボードから操作でき、スクリーンリーダーで機能と現在状態を認識できる。
- 狭い画面では横長の表・グラフを各領域内で横スクロール可能とし、ページ全体には不要な水平スクロールを発生させない。グラフの情報は文字・数値でも確認できる。
- JSON・CSVはブラウザー内で処理し、外部へ送信しない。

## 4. 受け入れ条件

- メッセージAPI、SQLite用コード、API応答型、関連テスト、SQLite依存関係がリポジトリから除去されている。
- READMEとアプリのメタデータにテンプレート由来の説明やメッセージ機能が残っていない。
- テーマを切り替えられ、選択が再読み込み後も維持される。試算条件・結果は継続保存されない。
- テーマ切替ボタンにアクセシブルな名前と押下状態があり、キーボードで操作できる。
- 狭い画面でページ全体に水平スクロールが発生せず、横長の表・グラフを各表示領域内で確認できる。
- サンプルCSV読込、投資計算、3ケース比較、JSON/CSV入出力、ダークモードの回帰テストが成功する。
- lint・型検査・本番ビルドが成功する。
