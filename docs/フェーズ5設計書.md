## 2. テンプレート機能の削除

以下は投資シミュレータから参照されていないため削除する。

- `lib/database.ts` と `__tests__/lib/database.test.ts`
- `src/app/api/message/route.ts` と `__tests__/src/app/api/message/route.test.ts`
- `src/types/api.ts`
- `better-sqlite3`、`@types/better-sqlite3` とロックファイル内の依存記録
- `.gitignore` の空になったデータベース用ルール

メッセージAPIを削除しても、サンプルCSVは既存の `/data/sample-properties.csv` 読込処理を維持する。既存のNext.jsセキュリティヘッダー設定も変更しない。

## 3. アプリ共通部

- `src/app/page.tsx` のページ見出しを唯一の `h1` とし、ヘッダーのアプリ名はブランド表示として段落要素にする。
- テーマ切替ボタンに固定のアクセシブルな名前 `ダークモード` と `aria-pressed` を付ける。アイコンは支援技術から隠し、`title` には現在のテーマを残す。
- `DarkModeProvider` は従来どおりテーマだけを `localStorage` の `theme` キーで維持する。試算条件の保存処理は追加しない。
- `layout.tsx` のメタデータ説明を取得・運用・売却の3ケース比較に合わせる。
- READMEに利用方法、データの扱い、検証コマンド、主要なディレクトリを記載する。
- `ProjectionCharts` の各グラフを縮小可能なグリッド項目にし、グラフ内だけで横スクロールする。狭い画面のページ全体の横はみ出しを防ぐ。
