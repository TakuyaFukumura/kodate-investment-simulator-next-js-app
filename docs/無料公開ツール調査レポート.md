# 無料公開ツール調査レポート

## 調査概要

2026年10月25日時点で、インターネット上から利用できる無料の不動産投資シミュレーションや計算ツールを調査した。特定のサービス名は記載せず、公開ページで確認できた機能を種類別に整理する。リンク先は機能を確認した公開ページであり、利用条件や機能は変更される場合がある。

今回確認した範囲では、単一の収支・利回り計算だけでなく、長期の資金繰り、税金、売却時の手残り、リスク条件の比較などを提供するものがある。一方で、無料利用の範囲、会員登録の要否、対応する物件種別、税計算の精度には違いがある。

## よく見られる入力項目と計算結果

### 入力項目

- **物件取得**：物件価格、購入時諸費用、自己資金、建物価格や構造、築年数、面積
- **賃貸運営**：満室想定家賃、入居率・空室率、家賃下落、管理費、修繕費、固定資産税、保険料など
- **融資**：借入額、金利、返済期間、返済方式
- **保有・売却**：保有期間、売却価格または価格変化、売却費用、残債
- **税務**：減価償却、所得税等の税率、譲渡時の税金

### 出力項目

- 表面利回り、実質利回り、NOI利回り、自己資金に対する収益率
- 月次・年次のキャッシュフローと長期の累計推移
- ローン返済額、元本返済額、残債、利息総額
- DSCRなど、収益に対する返済負担を示す指標
- 税引前・税引後の収支、減価償却による税効果の概算
- 売却時の残債・費用・税金を差し引いた手残り、IRR等
- 金利、空室率、家賃、修繕費などを変えたシナリオ比較

## 戸建て投資を対象にする際のポイント

汎用の収支計算フォームには「戸建て投資」を対象に含むと明記したものがある一方、確認したダウンロード型の資料のように区分マンション専用のものもある。物件種別に対応しているかだけでなく、戸建て固有の費用・前提を入力できるかが重要になる。

- 建物と土地の価格内訳、構造・築年数に応じた減価償却
- 購入時のリフォーム費用と、保有中の修繕・設備交換費用
- 一戸全体が空室になる期間を含む空室・募集期間の想定
- 管理委託の有無に応じた費用、固定資産税、保険料
- 融資額・金利・期間と、返済後に残る資金
- 保有年数ごとの売却価格、売却費用、残債、税引後手残り

特に、空室率や運営費率を一律の割合だけで入力する方式では、戸建ての長期空室や突発的な大規模修繕を十分に表現できないことがある。必要に応じて、修繕の時期・金額を年ごとに設定したり、複数条件を比較できたりするかを確認したい。

## 無料利用と試算結果の注意点

- 「無料」でも、会員登録が必要、利用回数に上限がある、詳細機能は有料などの違いがある。利用前に料金・登録条件を確認する。
- ダウンロード資料は、対応する物件種別、同時に扱える物件数、編集できる計算前提を確認する。
- 税引後の試算や減価償却は概算であることが多い。個人・法人の違い、他の所得、建物と土地の配分などをすべて反映するとは限らない。
- 家賃、空室、修繕、金利、売却価格などは将来の確定値ではない。結果は入力条件に基づく試算として扱い、複数シナリオで比較する。
- 投資判断や税務・融資の確定判断を代替するものではない。重要な判断では、契約資料や専門家に確認する。

## 今後のシミュレーターに活かせる機能

公開ツールに共通する基礎機能として、物件価格・取得費用・家賃・空室・運営費・融資条件を入力し、利回りと月次・年次キャッシュフローを算出する機能が挙げられる。戸建て向けには、さらに次の優先順位で検討するとよい。

1. **基本試算**：購入費用、家賃、空室、運営費、ローン返済を含む月次・年次収支と、利回り・残債を表示する。
2. **戸建て固有の費用**：建物・土地の内訳、購入時リフォーム、年ごとの修繕費や設備交換を入力できるようにする。
3. **長期・出口の比較**：家賃下落や空室、金利、修繕の前提を変えた複数ケースと、保有年数別の売却後手残りを比較する。
4. **税務と説明**：税引前・税引後を区別し、税や減価償却の計算前提、対象外項目、概算であることを画面に示す。
5. **保存・出力**：物件やシナリオを保存・比較し、結果を共有または出力する必要性を検討する。
