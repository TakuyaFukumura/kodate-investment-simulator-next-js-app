# プロダクト要件定義書

## 1. 目的と利用者

戸建て物件の取得・運用・売却について、利用者が入力した仮定から試算し、条件の異なるケースを比較できるようにする。主な利用者は、自分自身の購入検討・収支比較を行う個人利用者である。

本アプリの結果は税引前の概算であり、税務・融資判断や実際の投資成果を保証しない。

## 2. 現在の対象範囲

- リポジトリに同梱する架空物件のCSVを読み込み、画面で条件を編集して試算する。
- 取得前の基本収支、年次運用、修繕、ローン残債、売却後手残りを算出する。
- 基準・楽観・慎重の3ケースを比較する。
- 試算条件をJSONで入出力し、年次結果をCSVで出力する。
- ダークモードを提供する。

各機能の入力、計算式、境界条件、画面表示、エラー処理は[ドキュメント一覧](README.md)から該当するフェーズ別仕様を参照する。

## 3. 共通要件

### 計算と説明

- 結果には適用した条件、単位、計算前提、対象外の範囲を示す。
- グラフに依存せず、主要な結果を数値または表でも確認できるようにする。
- 不正な入力や読み込み失敗を明示し、無効な値から成功に見える結果を表示しない。
- 将来の家賃、空室、修繕、金利、売却価格は仮定であり、保証値として表現しない。

### データとプライバシー

- 同梱CSVは架空のサンプルであり、読み取り専用とする。外部CSVの取り込みは対象外。
- 試算条件・計算結果をアプリ内に継続保存せず、JSON/CSVのファイル操作はブラウザー内で行う。
- 継続保存するブラウザー内データはテーマ設定のみとし、試算条件や結果をサーバーへ送信しない。

### 操作性

- ダークモード切り替えを維持する。
- 読み込み中、読み込み失敗、入力エラーなどを区別して表示する。
- キーボード・支援技術で操作可能とし、狭い画面では表やグラフを適切にスクロールできるようにする。

## 4. 対象外

- 所得税・譲渡所得税等の正確な税額や税務申告計算。
- 融資審査や金融機関ごとの条件の再現。
- 市場価格、賃料、金利等の外部データ自動取得。
- アカウント、複数利用者、認証、クラウド同期。
- 投資判断、収益性、将来価格の保証。

## 5. 仕様の管理

- 利用者が決めた事項と未確認の暫定仕様は[意思決定記録](意思決定記録.md)で管理する。
- 完了状況と未決事項は[開発計画・進捗](戸建て投資シミュレータ開発計画書.md)を参照する。
- 無料公開ツールの調査は[背景資料](無料公開ツール調査レポート.md)として保存する。これは2026年10月時点の参考情報であり、現在の仕様より優先しない。
