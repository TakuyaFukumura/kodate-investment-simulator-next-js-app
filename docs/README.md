## 背景資料

- [無料公開ツール調査レポート](無料公開ツール調査レポート.md) は2026年10月時点の参考調査です。現行の要件や実装仕様ではありません。

フェーズ別文書と意思決定記録が現行仕様の根拠です。完了済みの一時的な解析レポートや初期の設計案は維持せず、必要な品質確認は現在のテスト・lint・build コマンドで行います。
