# フェーズ4 要件定義書：ケース比較・条件入出力・結果出力

## 1. 文書の状態

- **状態**：要件定義中（初版）
- **対象フェーズ**：フェーズ4
- **関連文書**：[開発計画書](戸建て投資シミュレータ開発計画書.md)、[プロダクト要件定義書](プロダクト要件定義書.md)、[意思決定記録](意思決定記録.md)
- **前提要件**：[フェーズ1要件定義書](フェーズ1要件定義書.md)、[フェーズ2要件定義書](フェーズ2要件定義書.md)、[フェーズ3要件定義書](フェーズ3要件定義書.md)

## 2. 目的と対象範囲

利用者が基準・楽観・慎重の3ケースを設定し、購入から運用・売却までの結果を比較できるようにする。試算条件はJSONファイルで入出力し、年次結果はCSVファイルとして出力する。試算条件や結果の継続保存は行わない。

### 2.1 対象機能

- 基準・楽観・慎重の固定3ケースを扱う。
- 基準ケースの条件を基に楽観・慎重ケースを複製し、複製後は各ケースを独立して編集する。
- 共通の保有期間を除き、基本試算・運用・売却の条件をケースごとに編集できる。
- 3ケースの結果を同時に比較し、選択した保有年の主要指標、年次詳細表、保有年数ごとの総損益グラフを表示する。
- 3ケースの入力条件を1つのJSONファイルにまとめて出力し、取り込む。
- 3ケース全体を検証し、問題がない場合だけ一括反映する。不正なファイルは反映せず、ケース名・項目名・原因を表示する。
- 3ケースの年次結果を1つのCSVファイルに出力する。

### 2.2 対象外

- DBおよびブラウザー内への継続保存。
- 比較ケース数の追加・削除、ケース名の変更。
- 税引後損益など、フェーズ1〜3で対象外とした計算。
- 条件や結果を外部サーバーへ送信する機能。

## 3. ケース条件

| 項目 | 要件 |
| --- | --- |
| ケース | 基準・楽観・慎重の3ケース固定 |
| ケース作成 | 楽観・慎重は基準の条件を複製して用意する |
| 複製後の編集 | 3ケースは独立して編集する。基準を変更しても複製済みケースには自動反映しない |
| 保有期間 | 3ケース共通 |
| 編集対象 | 共通の保有期間を除き、基本試算・運用・売却の全条件 |
| 入力画面 | タブ等を用い、1ケースずつ条件を編集する |
| 結果画面 | 3ケースを同時に比較する |

各ケースの入力値・検証範囲は、フェーズ1〜3の要件に従う。既存の入力検証に不適合があるケースの計算結果は表示しない。

## 4. 比較結果の表示

- 選択中の保有年について、NOI・年間運営CF・売却後手残り・総損益・単純損益率を3ケース横並びで表示する。
- 初期表示年は、共通の保有期間の最終年とする。利用者は表示する保有年を選択できる。
- 年次詳細表で3ケースの年次運用・返済・売却結果を確認できる。
- 年次推移グラフは保有年数ごとの総損益を指標とし、基準・楽観・慎重の3本の折れ線で表示する。
- 金額・比率の単位と表示精度は、各指標の既存フェーズ要件に合わせる。

## 5. JSON条件ファイル

- 基準・楽観・慎重の3ケースの入力値を1つのファイルにまとめる。
- 同梱CSVの物件ID参照ではなく、CSVに依存せず同一条件を復元できるよう各ケースの入力値をすべて含める。
- 形式バージョンを含める。未対応バージョンは取り込みを拒否する。
- 取り込み時は、ファイル構造、形式バージョン、3ケースの全条件を検証する。
- 全検証に成功したときだけ3ケースを一括置換する。部分的な反映はしない。
- 構造・バージョン・入力値に問題がある場合は現在のケース条件を維持し、エラーを表示する。入力値のエラーは該当ケース名・項目名・原因を示す。

具体的なJSONキー、ファイル名、シリアライズ方式は設計書で定義する。

## 6. 年次結果CSV

- 基準・楽観・慎重の全ケースを1つのCSVに出力する。
- 1ケース・1年を1行とし、各行にケース名・年・物件名を含める。
- 列見出しは日本語とする。
- 文字コードはUTF-8 BOM付き、区切り文字はカンマ、先頭行はヘッダーとする。
- 金額は万円単位で小数第2位まで出力する。数値セルに通貨記号・桁区切りを付けない。
- 運用項目として満室想定家賃、空室損失、実効家賃、運営費、NOI、修繕費を含める。
- 融資・運営結果として元金返済、利息返済、返済合計、期末残債、年次CF、累計CF、DSCRを含める。
- 売却結果として売却価格、仲介手数料、印紙税、ローン完済手数料、その他売却費用、売却後手残り、総損益、単純損益率を含める。
- 売却試算が成立しない年は、算出不能な売却価格・仲介手数料・売却後手残り・総損益・単純損益率を空欄にする。印紙税・ローン完済手数料・その他売却費用・残債など既知の値は出力する。

具体的な列名・列順・各値の範囲は設計書で定義する。入力条件ではなく年次結果を出力対象とする。

## 7. 受け入れ条件

- 3ケースの条件を個別に編集でき、基準ケースの変更が楽観・慎重に自動反映されない。
- 保有期間を共通で変更すると、3ケースの計算対象年がそろう。
- 選択した保有年の主要指標と、3ケースの年次詳細・総損益グラフを確認できる。
- 有効なJSONを取り込むと3ケースがまとめて置き換わり、同じ条件から同じ試算結果を再現できる。
- 不正なJSONや未対応バージョンを取り込んでも現在の3ケースは変わらず、利用者が修正箇所を特定できるエラーが表示される。
- CSVは3ケースの全対象年を含み、ケース名・年・物件名を行単位で識別できる。
- CSVの文字コード・区切り・列見出し・金額単位・精度が本書の要件に合い、売却不可時のセルは空欄となる。
- フェーズ1〜3の計算・表示、ダークモード、サンプルCSV読込に回帰がない。

## 8. 設計時に確定する事項

- JSONの具体的な構造、バージョン値、ファイル名、および不正形式のエラー分類。
- CSVの具体的な列名・列順と、運用・融資・売却結果から出力する項目の対応。
- JSON・CSVのダウンロード操作とファイル名。
- 比較画面の詳細な配置、年選択コントロール、各指標の書式。

決定済み事項の根拠は[意思決定記録](意思決定記録.md)のQ40〜Q68を参照する。
